# Configuración Laptop Acemagic AX15

Repositorio de configuración y documentación de mi estación de trabajo para ciberseguridad, programación y creación de contenido.

## Especificaciones del Hardware

- **Modelo:** Acemagic AX15
- **Procesador:** Intel N97 (4 núcleos, 4 hilos)
- **RAM:** 16 GB
- **Almacenamiento:** 512 GB SSD (particionado)
- **Sistema Operativo:** Windows 11 Pro + Kali Linux (VM)

- Visual Studio Code

- OBS Studio

### Kali Linux (VM)
- Versión 2026.1
